# 1. 홈페이지 사용·기술 설명서

**(재)안양공원묘원** 공개 웹사이트용입니다.  
대상: 방문객·연고자·문의 고객, 그리고 공개 화면을 설명할 직원.  
사이트 주소 예: `https://mp-anyang.onrender.com`

이 문서는 **유저 매뉴얼**(화면 이용 방법)과 **테크니컬 매뉴얼**(경로·데이터·운영 참고)을 한 권에 담습니다.  
고인명·개인 전화·계정 비밀번호는 넣지 않습니다.

---

## A. 유저 매뉴얼

### A-1. 시작하기

1. 브라우저에서 사이트에 접속합니다.
2. 상단(또는 모바일 메뉴)에서 다음을 고릅니다.
   - **공원소개**
   - **분양안내**
   - **이용안내**
   - **둘러보기**(갤러리)
   - **고객센터**
3. **사이트맵**(`/sitemap`)에서 전체 메뉴를 한눈에 볼 수 있습니다.
4. 언어는 한국어·English·日本語·中文을 고를 수 있습니다(헤더 언어 전환).

메인(`/`)에는 히어로 영상·배경음악, 연락·지도·SNS 안내, 이벤트·팝업이 있을 수 있습니다. 팝업은 관리자가 올린 경우에만 나타납니다.

### A-2. 공원소개

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 인사말 | `/intro/greeting` | 공원·재단 소개 인사 |
| 공원 특징 | `/intro/features` | 입지·시설 등 특징 |
| 오시는 길 | `/intro/directions` | 주소, 지도·길찾기 링크 |

**이용 팁**
- 오시는 길에서 네이버·카카오 지도/길찾기로 이동할 수 있습니다.
- 공개 도로명 주소는 사이트에 표시된 문구를 따릅니다.

### A-3. 분양안내

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 매장묘 | `/lots/burial` | 매장묘 안내 |
| 평장묘 | `/lots/lawn` | 평장묘 안내 |
| 봉안묘 | `/lots/columbarium` | 봉안묘 안내 |
| 리모델링 | `/lots/remodeling` | 리모델링 안내 |
| 분양가·잔여 | `/lots/prices` | 분양가·잔여 안내 |

본문·사진은 홈페이지관리에서 고친 내용이 반영됩니다. 최신 가격·잔여는 전화·방문 상담으로 다시 확인하는 것이 안전합니다.

### A-4. 이용안내

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 분양 절차 | `/guide/procedure` | 분양 진행 단계 |
| 관리비 | `/guide/fees` | 관리비 안내(공개) |
| 서비스 | `/guide/services` | 부대 서비스 |
| 장례·안치 | `/guide/funeral` | 장례·안치 안내, 서류 PDF(등록된 경우) |

상단 메뉴에 없어도 링크로 열릴 수 있는 화면:
- 벌초 신청 `/guide/weeding`
- 결제·계좌 안내 `/pay`(안내 문구가 “미확정”인 항목은 전화 확인)
- 카카오채널 `/support/kakao`

### A-5. 둘러보기(갤러리)

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 공원 갤러리 | `/gallery` | 전경·묘종별 사진 |

1. 태그(전체·전경·매장묘·평장묘·봉안묘·리모델링 등)로 걸러 봅니다.
2. 격자 썸네일을 누르면 원본에 가깝게 확대합니다.
3. 사진이 비어 있으면 관리자가 아직 올리지 않았거나, 배포 후 파일이 비어 있을 수 있습니다(기술편 B-4).

### A-6. 고객센터

| 화면 | 경로 | 무엇을 하냐 |
|------|------|-------------|
| 공지사항 | `/support/notices` | 목록·상세(`/support/notices/[slug]`) |
| 문의·상담 | `/support/inquiry` | 문의 양식 제출 |
| 묻고답하기 | `/support/faq` | FAQ 열람 |

**문의 제출**
1. 필수 항목을 채웁니다.
2. 제출 후 접수됩니다.
3. 관리자 답변은 **내부 메모**로 남고, 자동 메일 발송은 하지 않습니다. 회신은 전화·방문 등 기존 방식으로 이루어질 수 있습니다.

### A-7. 기타 공개 화면

| 화면 | 경로 | 비고 |
|------|------|------|
| 개인정보 처리 | `/privacy` | 푸터 등에서 연결 |
| 직원 로그인 | `/account/login` | 일반 고객용 아님 |
| 내 계정 | `/account` | 로그인 후 |

### A-8. 자주 묻는 이용 문제

| 증상 | 확인할 일 |
|------|-----------|
| 메뉴가 안 보임 | 화면 폭·햄버거 메뉴, 언어 설정 |
| 문의가 안 보내짐 | 필수 칸, 네트워크, 잠시 후 재시도 |
| 지도가 안 열림 | 외부 지도 사이트 차단·팝업 |
| 영상이 안 나옴 | 브라우저 자동재생·음소거 정책, 관리자 등록 여부 |

## B. 테크니컬 매뉴얼

### B-1. 제품 위치

- 프레임워크: Next.js App Router
- 공개 NAV 정의: `src/lib/site.ts`의 `NAV`
- 사이트 상수(명칭·주소·지도 좌표·SNS): `SITE`, `MAP`, `SOCIAL_URLS`
- 기본 공개 URL: `DEFAULT_SITE_URL` / 환경변수 `SITE_URL`

### B-2. 경로 맵(공개)

```
/                          메인
/intro/greeting|features|directions
/lots/burial|lawn|columbarium|remodeling|prices
/guide/procedure|fees|services|funeral|weeding
/gallery
/support/notices|/notices/[slug]|inquiry|faq|kakao
/privacy
/pay
/sitemap
```

### B-3. 콘텐츠 출처

| 구분 | 예 | 출처 |
|------|-----|------|
| CMS 본문 | 인사말, 특징, 분양 각 종, 분양가 | Mongo(또는 로컬) CMS + 코드 폴백 |
| 고정 UI | 분양 절차 단계 | 코드(`SALE_STEPS` 등) |
| 갤러리 | `/gallery` | 관리 `/manage/gallery` 데이터·파일 |
| 공지·FAQ·문의 | 고객센터 | 관리 화면에서 CRUD |
| 메인 히어로·팝업 | `/` | `/manage/home-hero`, `/manage/announcements` |

공개 페이지는 **로그인 없이** 읽습니다. 직원 메뉴(`/work`, `/manage`, `/supervisor`)는 이 권 범위가 아닙니다.

### B-4. 미디어·배포

- 갤러리·일부 업로드는 `public/uploads` 및/또는 Mongo GridFS(`/api/uploads/...`)를 씁니다.
- Render 등 **재배포 시 로컬 디스크가 초기화**되면, 디스크만 쓰던 파일이 비어 보일 수 있습니다.
- 운영 시: 재배포 후 갤러리·히어로·장례 PDF를 확인하고, 영구 저장(Mongo/외부) 여부를 점검합니다.

### B-5. 다국어

- 문구 키: `src/lib/i18n.ts`
- 서버 로케일: `readLocale` 등
- 문서·캡처는 한국어 기준으로 두고, 번역 키만 기술편에 언급하면 충분합니다.

### B-6. 개인정보·문서 정책

- 문의 폼·공지에 올라온 개인정보는 설명서·캡처에 넣지 않습니다.
- 공개 전화·주소는 사이트에 이미 노출된 `SITE` 값만 인용합니다.
- `/pay` 등 미확정 안내는 “확정 전”으로 표시하고 임의 계좌를 적지 않습니다.

### B-7. 점검 체크리스트(공개)

- [ ] 메인 로드, 히어로·팝업(있을 때)
- [ ] 공원소개 3화면
- [ ] 분양안내 5화면
- [ ] 이용안내 4화면(+ 필요 시 벌초·결제)
- [ ] 갤러리 태그·확대
- [ ] 공지 목록·상세, 문의 제출, FAQ
- [ ] 사이트맵·언어 전환·개인정보
