# 1. 홈페이지 사용·기술 설명서

**(재)안양공원묘원** 공개 웹사이트용입니다.  
대상: 방문객·연고자·문의 고객, 그리고 공개 화면을 설명할 직원.  
사이트 주소: `https://www.anyangmp.com`

이 문서는 **유저 매뉴얼**(화면 이용 방법)과 **테크니컬 매뉴얼**(경로·데이터·운영 참고)을 한 권에 담습니다.  
고인명·개인 전화·계정 비밀번호는 넣지 않습니다.

---

## A. 유저 매뉴얼

### A-1. 시작하기

1. 브라우저에서 사이트에 접속합니다.
2. 왼쪽 **탐색기**(또는 모바일 메뉴)에서 다음을 고릅니다.
   - **공원소개**
   - **분양안내**
   - **이용안내**
   - **둘러보기**(갤러리)
   - **고객센터**
3. 헤더·탐색기의 **사이트맵**(`/sitemap`)에서 전체 메뉴를 한눈에 볼 수 있습니다.
4. 언어는 한국어·English·中文을 고를 수 있습니다(헤더 국기).

메인(`/`)에는 히어로 영상·배경음악, 연락·지도·SNS 안내, 이벤트·팝업이 있을 수 있습니다. 팝업은 관리자가 올린 경우에만 나타납니다.

### A-2. 공원소개

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 인사말 | `/intro/greeting` | 공원·재단 소개 인사 |
| 공원 특징 | `/intro/features` | 입지·시설 등 특징 |
| 오시는 길 | `/intro/directions` | 주소, 지도·길찾기 링크 |

**이용 팁**
- 오시는 길에서 네이버·카카오 지도/길찾기로 이동할 수 있습니다.
- 공개 도로명 주소는 사이트에 표시된 문구를 따릅니다.
- 본문은 홈페이지관리에서 고친 내용이 반영됩니다.

### A-3. 분양안내

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 매장묘 | `/lots/burial` | 매장묘 안내 |
| 평장묘 | `/lots/lawn` | 평장묘 안내 |
| 봉안묘 | `/lots/columbarium` | 봉안묘 안내 |
| 리모델링 | `/lots/remodeling` | 리모델링 안내 |
| 분양가·잔여 | `/lots/prices` | 분양가·잔여 안내 |

본문·사진은 홈페이지관리에서 고친 내용이 반영됩니다. 최신 가격·잔여는 전화·방문 상담으로 다시 확인하는 것이 안전합니다.

### A-4. 이용안내

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 분양 절차 | `/guide/procedure` | 분양 진행 단계 |
| 관리비 | `/guide/fees` | 관리비 안내(공개) |
| 서비스 | `/guide/services` | 부대 서비스 |
| 장례·안치 | `/guide/funeral` | 장례·안치 안내, 매장·화장 서류 PDF |

**장례·안치 서류**
1. **매장 시 서류** / **화장 시 서류**가 따로 보입니다.
2. 등록된 서류 이름을 누르면 **모달**에서 PDF를 볼 수 있고, 필요하면 내려받을 수 있습니다.
3. 미등록 서류는 「준비 중」으로 표시됩니다.
4. 연고자 신분증은 안내만 있으며 PDF 다운로드가 없습니다.

상단 메뉴에 없어도 링크로 열릴 수 있는 화면:
- 벌초 신청 `/guide/weeding`
- 결제·계좌 안내 `/pay`(안내 문구가 “확인 필요”인 항목은 전화 확인)
- 카카오채널 `/support/kakao`

### A-5. 둘러보기(갤러리)

| 화면 | 경로 | 무엇을 보나 |
|------|------|-------------|
| 공원 갤러리 | `/gallery` | 전경·묘종별·일반 사진 |

1. 태그(전체·전경·매장묘·평장묘·봉안묘·리모델링·일반 등)로 걸러 봅니다.
2. 격자 썸네일을 누르면 원본에 가깝게 확대합니다.
3. 사진이 비어 있으면 관리자가 아직 올리지 않았거나, 배포 후 파일이 비어 있을 수 있습니다(기술편 B-4).

### A-6. 고객센터

| 화면 | 경로 | 무엇을 하냐 |
|------|------|-------------|
| 공지사항 | `/support/notices` | 목록·상세(`/support/notices/[slug]`) |
| 문의·상담 | `/support/inquiry` | 문의 목록 열람·문의하기 |

**문의·상담 이용**
1. 본문에 **문의 목록**이 보입니다. 각 건에 **미답변** / **답변완료**가 표시됩니다.
2. 오른쪽 위 **문의하기**를 누르면 모달에서 작성합니다.
3. **공개 여부**를 고릅니다.
   - **일반**: 이름·연락처는 일부만 보이고, 내용·답변은 목록에서 볼 수 있습니다.
   - **비밀**: 비밀번호를 설정합니다. 비밀번호를 아는 분만 내용·답변을 볼 수 있습니다.
4. 제출하면 목록에 올라갑니다. 직원이 답변하면 **답변완료**와 답변 내용이 목록에 표시됩니다.
5. 비밀글은 **비밀번호 확인**으로 열어 봅니다.
6. 급하면 사이트에 안내된 전화로 연락합니다.

### A-7. 기타 공개 화면

| 화면 | 경로 | 비고 |
|------|------|------|
| 개인정보 처리 | `/privacy` | 푸터 등에서 연결 |
| 직원 로그인 | 헤더 로그인 아이콘 | 일반 고객용 아님 |
| 사이트맵 | `/sitemap` | 구역별 카드 |

### A-8. 자주 묻는 이용 문제

| 증상 | 확인할 일 |
|------|-----------|
| 메뉴가 안 보임 | 화면 폭·탐색기·언어 설정 |
| 문의가 안 보내짐 | 필수 칸, 비밀글 비밀번호 확인, 네트워크 |
| 비밀글이 안 열림 | 작성 시 비밀번호와 같은지 확인 |
| 지도가 안 열림 | 외부 지도 사이트 차단·팝업 |
| 영상이 안 나옴 | 브라우저 자동재생·음소거 정책, 관리자 등록 여부 |
| PDF가 「준비 중」 | 관리자가 아직 서류를 올리지 않음 |

## B. 테크니컬 매뉴얼

### B-1. 제품 위치

- 프레임워크: Next.js App Router
- 공개 NAV 정의: `src/lib/site.ts`의 `NAV`
- 사이트 상수(명칭·주소·지도 좌표·SNS): `SITE`, `MAP`, `SOCIAL_URLS`
- 기본 공개 URL: `SITE_URL` / `https://www.anyangmp.com`

### B-2. 경로 맵(공개)

```
/                          메인
/intro/greeting|features|directions
/lots/burial|lawn|columbarium|remodeling|prices
/guide/procedure|fees|services|funeral|weeding
/gallery
/support/notices|/notices/[slug]|inquiry|kakao
/privacy
/pay
/sitemap
```

### B-3. 콘텐츠 출처

| 구분 | 예 | 출처 |
|------|-----|------|
| CMS 본문 | 인사말, 특징, 오시는 길, 분양, 절차·관리비·서비스·장례 | Mongo(또는 로컬) CMS + 코드 폴백 |
| 갤러리 | `/gallery` | 관리 `/manage/gallery` |
| 공지·문의 | 고객센터 | 관리 화면 |
| 장례 PDF | `/guide/funeral` | `/manage/pages/funeral` 서류 등록 |
| 메인 히어로·팝업 | `/` | `/manage/home-hero`, `/manage/announcements` |

공개 페이지는 **로그인 없이** 읽습니다. 직원 메뉴(`/work`, `/manage`, `/supervisor`)는 이 권 범위가 아닙니다.

### B-4. 미디어·배포

- 갤러리·일부 업로드는 `public/uploads` 및/또는 Mongo GridFS(`/api/uploads/...`)를 씁니다.
- Render 등 **재배포 시 로컬 디스크가 초기화**되면, 디스크만 쓰던 파일이 비어 보일 수 있습니다.
- 운영 시: 재배포 후 갤러리·히어로·장례 PDF를 확인하고, 영구 저장(Mongo/외부) 여부를 점검합니다.

### B-5. 다국어

- 문구 키: `src/lib/i18n.ts`
- 홈페이지관리에서 한글을 저장하면 영어·중국어가 자동 번역될 수 있습니다.
- Enter는 줄바꿈, 빈 줄은 문단으로 공개됩니다.

### B-6. 개인정보·문서 정책

- 문의·공지에 올라온 개인정보는 설명서·캡처에 넣지 않습니다.
- 공개 전화·주소는 사이트에 이미 노출된 `SITE` 값만 인용합니다.
- 비밀 문의 비밀번호는 해시로 저장합니다.

### B-7. 점검 체크리스트(공개)

- [ ] 메인 로드, 히어로·팝업(있을 때)
- [ ] 공원소개 3화면
- [ ] 분양안내 5화면
- [ ] 이용안내 4화면(+ 필요 시 벌초·결제)
- [ ] 장례 서류 모달 PDF
- [ ] 갤러리 태그·확대
- [ ] 공지 목록·상세
- [ ] 문의 목록·문의하기(일반/비밀)·답변 표시
- [ ] 사이트맵·언어 전환·개인정보
