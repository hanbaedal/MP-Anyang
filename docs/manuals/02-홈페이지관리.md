# 2. 홈페이지관리 사용·기술 설명서

공개 사이트 문구·사진·공지·문의를 **직원이 고치는** 영역입니다.  
대상: **관리자(`admin`)**, **슈퍼바이저(`supervisor`)**.  
경영(`ceo`)은 이 메뉴에 들어가지 않습니다.

사이트 주소: `https://www.anyangmp.com`

---

## A. 유저 매뉴얼

### A-1. 들어가기

1. 헤더 로그인 아이콘으로 로그인합니다.
2. 로그인 후 탐색기·사이트맵에서 **홈페이지관리**를 고르거나 `/manage`로 이동합니다.
3. **관리자**는 한국시간 **09:00–18:00**에만 세션이 유지됩니다.  
   **슈퍼바이저**는 시간 제한이 없습니다.

### A-2. 관리 홈 `/manage`

대시보드 카드로 각 메뉴로 이동합니다.  
탐색기의 홈페이지관리 서브메뉴 순서는 공개 메뉴 순서와 맞춰 둡니다.  
갤러리 등 업로드는 **재배포 후 파일이 비는지** 확인합니다.

### A-3. 메뉴별 사용법

| 메뉴 | 경로 | 하는 일 |
|------|------|---------|
| 메인 영상·음악 | `/manage/home-hero` | 메인 배경 영상·BGM 등록·변경 |
| 메인 이벤트·팝업 | `/manage/announcements` | 접속 시 뜨는 이벤트·팝업 |
| 갤러리 | `/manage/gallery` | 둘러보기 사진(일반·종류별) 올리기·고치기·지우기 |
| CMS 본문 | `/manage/pages/{slug}` | 공개 페이지 본문 편집(아래 표) |
| 장례·안치(본문+서류) | `/manage/pages/funeral` | 절차 문구 + 공공서류 PDF 4종 |
| 공지 | `/manage/notices` | 고객센터 공지 작성 |
| 문의 | `/manage/inquiries` | 문의 열람·답변·문자·삭제 |
| 관리자 계정 | `/manage/admins` | **슈퍼바이저만** 직원 계정 관리 |

**CMS 본문 slug (공개와 연동)**

| slug | 공개 화면 |
|------|-----------|
| `greeting` | `/intro/greeting` |
| `features` | `/intro/features` |
| `directions` | `/intro/directions` |
| `burial` | `/lots/burial` |
| `lawn` | `/lots/lawn` |
| `columbarium` | `/lots/columbarium` |
| `remodeling` | `/lots/remodeling` |
| `prices` | `/lots/prices` |
| `procedure` | `/guide/procedure` |
| `fees` | `/guide/fees` |
| `services` | `/guide/services` |
| `funeral` | `/guide/funeral` |

한글을 저장하면 영어·중국어가 자동 번역될 수 있습니다. Enter=줄바꿈, 빈 줄=문단입니다.

### A-4. 갤러리 「일반」사진

1. `/manage/gallery`에서 태그를 **일반**으로 사진을 올립니다.
2. 공개 `/gallery`에서도 볼 수 있습니다.
3. 홈페이지관리(메인 팝업·분양 CMS 사진 등)에서 **갤러리에서 고르기**로 재사용할 수 있습니다.

### A-5. 장례·안치 서류 PDF

경로: `/manage/pages/funeral` 하단 **공공서류 PDF (4종)**

등록 서류(한 번만 올리면 공개 매장/화장 목록에 조합됨):
1. 사망진단서 1부
2. 화장증명서 1부
3. 고인 포함 가족관계증명서 또는 제적등본 1부
4. 검사지휘서 1부(사고사인 경우)

**PDF 올리기** 버튼을 누르면 파일을 고르고 바로 업로드됩니다.  
공개 `/guide/funeral`에서는 매장 시·화장 시 목록이 따로 보이며, 등록된 서류는 모달로 미리보기됩니다.

### A-6. 문의 관리 `/manage/inquiries`

1. 접수된 문의(일반/비밀)를 목록으로 봅니다.
2. **답변**을 누르면 모달이 열립니다.
3. 답변을 적은 뒤 버튼을 고릅니다.
   - **문자보내기**: 답변 저장 + 문의 휴대폰으로 솔라피 문자 발송
   - **완료**: 답변 저장만(문자 없음)
4. 어느 쪽이든 저장되면 공개 `/support/inquiry` 목록에 답변이 표시됩니다.
5. **삭제**로 문의를 지우면 공개 목록에서도 사라집니다(복구 없음).
6. 솔라피 잔액이 부족하면 「문자보내기」에 빨간 경고가 보입니다. 「완료」는 가능합니다.
7. 발신번호 기본값: `01051492949` (솔라피 콘솔 사전등록·잔액 충전 필요)

### A-7. 권장 작업 순서

1. 메인 영상·팝업 확인  
2. CMS 본문(인사말·분양·이용안내 등) 수정 후 공개 URL 미리보기  
3. 갤러리·장례 PDF 업로드 후 `/gallery`, `/guide/funeral` 확인  
4. 공지 게시  
5. 문의함에서 답변(필요 시 문자)·삭제 정리  

### A-8. 하지 말 것

- 문자를 보내지 않았는데 “문자로 회신했다”고 안내하지 않습니다. 「문자보내기」를 눌렀을 때만 문자가 갑니다.
- 갤러리에 개인이 식별되는 묘비 클로즈업을 올릴 때는 내부 기준을 따릅니다.
- 관리자 계정 화면은 슈퍼바이저가 아닌데 URL을 직접 열어 쓰지 않습니다.

### A-9. 문제 해결(사용자)

| 증상 | 조치 |
|------|------|
| `/manage`가 로그인으로 감 | 역할이 admin/supervisor인지 확인 |
| ceo로 로그인했는데 CMS가 안 보임 | 정상. 경영관리만 사용 |
| 근무 외 시간에 admin 끊김 | 정상(09–18 KST). 슈퍼바이저로 긴급 작업 |
| 갤러리 올린 뒤 공개에 없음 | 태그·게시 상태, 새로고침, 재배포 직후면 B-3 |
| PDF 올리기가 안 됨 | PDF만·10MB 이하, 버튼으로 파일 선택 |
| 문자가 안 감 | 「문자보내기」선택 여부, 솔라피 잔액·발신번호 등록 |
| `/manage/admins`가 `/manage`로 돌아감 | admin 계정임. 슈퍼바이저에게 요청 |

## B. 테크니컬 매뉴얼

### B-1. 접근 제어

```
requireCmsStaff()
- isCmsStaff: supervisor | admin
- ceo → 경영 홈으로 redirect
- 비로그인 → /?login=1

requireCmsStaff(true)  // 관리자 계정
- role === supervisor 만 통과
```

NAV: `src/lib/manage-nav.ts`의 `manageNavItems()`

### B-2. 데이터·API

- 공지·문의·CMS·갤러리 메타: Mongo(또는 로컬 JSON 폴백)
- 업로드: `public/uploads/...` 및 GridFS → `/api/uploads/...`
- 문의 답변 SMS: `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, (선택) `SOLAPI_FROM`
- 관리 API는 직원 세션·역할 검사가 필요합니다.

### B-3. 갤러리·업로드·재배포

관리 화면 안내 요지:
> 올린 파일은 `public/uploads`에 저장될 수 있고, Render 디스크는 재배포 때 비워질 수 있습니다.

**운영 권장**
1. Mongo GridFS(또는 외부 스토리지) 경로를 확인한다.
2. 배포 직후 `/gallery`, 메인 히어로, 장례 PDF를 연다.
3. 비어 있으면 재업로드 또는 DB/스토리지 복구.

### B-4. 문의 처리 모델

- 고객 제출 → DB 저장(일반/비밀, 비밀은 비밀번호 해시)
- 직원 **완료** → 공개 목록에 답변 표시, 문자 없음
- 직원 **문자보내기** → 공개 목록 답변 + 솔라피 SMS/LMS
- 직원 **삭제** → 관리·공개 목록에서 제거

### B-5. CMS와 공개 연동

- CMS slug를 저장하면 해당 공개 페이지에 반영됩니다.
- 장례는 CMS 문구 + 서류 PDF 4종이 한 관리 화면에 있습니다.
- CMS가 비면 코드 폴백 문구가 나올 수 있습니다.

### B-6. 점검 체크리스트

- [ ] admin·supervisor로 `/manage` 진입
- [ ] ceo는 CMS 미진입
- [ ] 본문 수정 → 공개 URL 반영(자동 번역 포함)
- [ ] 갤러리 일반 사진 → 공개·홈 관리 재사용
- [ ] 장례 PDF 4종 업로드 → 공개 모달
- [ ] 문의 완료 / 문자보내기 / 삭제
- [ ] 솔라피 잔액·발신번호 확인
