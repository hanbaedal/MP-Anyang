# 3. 업무프로그램 사용·기술 설명서

직원용 **일상 업무 조회·재고·매입·매출** 영역입니다.  
대상: **슈퍼바이저·관리자·CEO** 전원(`requireStaff`).  
원본 묘원 프로그램의 **읽기용 복사본**을 보는 화면이 많습니다. 원본을 직접 고치는 화면이 아닙니다.

> **중요:** 메뉴 이름이 같아도 `/supervisor/*`와는 다릅니다.  
> 슈퍼바이저 전용 계약부·원장·일지·기초정보는 **05-슈퍼바이저**를 봅니다.

---

## A. 유저 매뉴얼

### A-1. 들어가기

1. 로그인 후 사이트맵에서 **업무프로그램**을 엽니다.
2. 기본 진입은 보통 `/work/contracts`입니다.
3. 원본이 아직 안 붙어 있거나 복사본이 비면 “원본 연결 전” 안내가 나올 수 있습니다. 슈퍼바이저에게 DB 업데이트를 요청합니다.

### A-2. 메뉴 한눈에

| 메뉴 | 경로 | 용도 |
|------|------|------|
| 계약관리 | `/work/contracts` | 계약 목록 조회(연도·묘번·매장일 등) |
| 관리비내역 | `/work/fees` | 기간·납부상태로 관리비 조회 |
| 영수증관리 | `/work/receipts` | 영수증 목록·패널 |
| 거래처관리 | `/work/partners` | 거래처 |
| 부자재등록 | `/work/materials` | 부자재 |
| 상품등록 | `/work/products` | 상품 |
| 구매관리 | `/work/orders` | 구매(발주) |
| 매입장 | `/work/purchases` | 매입 |
| 매출장 | `/work/statements` | 매출 |
| 재고장 | `/work/inventory` | 재고(상품·부자재) |

### A-3. 계약·관리비·영수증(조회)

**계약관리**
- 검색 조건으로 목록을 좁힙니다.
- 상세는 복사본에 있는 범위만 보입니다.
- “원본처럼 저장·삭제”가 필요하면 슈퍼바이저 계약 화면·원본 프로그램을 확인합니다.

**관리비내역**
- 청구(또는 조회) 기간, 납부 구분을 넣고 조회합니다.
- 화면은 역할·구현에 따라 목록 중심입니다.

**영수증관리**
- 기간·묘번·상태로 찾고, 선택 시 우측/패널에 내역을 봅니다.

### A-4. 거래처·상품·재고 흐름(개념)

권장 순서(현장 운영에 맞게 조정):
1. 거래처 등록  
2. 부자재·상품 등록  
3. 구매(발주) → 매입장 반영  
4. 매출장 작성  
5. 재고장에서 수량 확인  

각 화면에서 **필수 칸·선택 품목**이 비면 저장이 거절될 수 있습니다. 오류 문구를 읽고 다시 시도합니다.

### A-5. 없는·리다이렉트되는 경로

| 경로 | 동작 |
|------|------|
| `/work/reports` | `/work/contracts`로 리다이렉트 → 실제 업무보고는 `/supervisor/reports` |
| `/work/master` | 동일 → 기초정보는 `/supervisor/base` |

설명서·교육에서 “업무프로그램 안의 업무보고/기초정보”라고 말하지 말고, **슈퍼바이저 메뉴**로 안내합니다.

### A-6. 문제 해결

| 증상 | 조치 |
|------|------|
| 목록이 비어 있음 | DB 업데이트·원본 연결, 필터 초기화 |
| 로그인 후 업무 메뉴 없음 | 직원 역할인지 확인 |
| admin 근무외 시간 끊김 | 09–18 KST 제한 |
| 업무보고가 계약으로 감 | 정상. 슈퍼바이저 → 업무보고/현황 |

## B. 테크니컬 매뉴얼

### B-1. 접근

- `/work/*` 레이아웃: `requireStaff` (supervisor | admin | ceo)
- 경영 전용 `/work/exec/*`는 **04-경영관리** (status staff만)

### B-2. 데이터 모델(개요)

- 계약·관리비·영수증 등: 원본 Cemetery에서 끌어온 **복사본**(Mongo `contracts`, `fees`, `receipts` 등 또는 로컬 JSON)
- 거래처·상품·재고 계열: 사이트 자체 업무 DB/컬렉션(구현 파일은 `work-*` 스토어 계열)
- 수동 전체 갱신·새벽 차분 갱신: 슈퍼바이저 `/work/sync` 및 타이머(`work-sync-timer`) — **05권**

### B-3. 업무 vs 슈퍼바이저

| 항목 | `/work/...` | `/supervisor/...` |
|------|-------------|-------------------|
| 대상 | 전 직원 | supervisor만 |
| 계약 | 복사본 조회 중심 | 검색·계약부·Mongo 운영 |
| 관리비·영수증 | 조회 UI | 원본형 검색·모달·저장 필드 |
| 업무보고·기초정보 | 리다이렉트 | 실화면 |

교육 시 표로 벽에 붙여 두는 것을 권합니다.

정의: `src/lib/work-nav.ts`  
사이트맵: `isStaffRole`이면 `work.program` 그룹에 노출.
