# 4. 경영관리 사용·기술 설명서

계약·관리비를 **집계·현황**으로 보는 경영 화면입니다.  
대상: **슈퍼바이저(`supervisor`)**, **CEO(`ceo`)** (`requireStatusStaff`).  
관리자(`admin`)는 이 메뉴가 사이트맵에 없습니다.

일상 목록 조회는 03-업무프로그램, 원장·동기화는 05-슈퍼바이저입니다.

---

## A. 유저 매뉴얼

### A-1. 들어가기

1. CEO 또는 슈퍼바이저로 로그인합니다.
2. 사이트맵에서 **경영관리**를 고릅니다.
3. 기본 진입: `/work/exec/fees`(올해 관리비).  
   `/work/exec`, `/work/overview`는 첫 화면으로 이어질 수 있습니다.

### A-2. 메뉴

| 메뉴 | 경로 | 보는 내용 |
|------|------|-----------|
| 올해 관리비 | `/work/exec/fees` | 당해 관리비 현황 |
| 미납 명단 | `/work/exec/unpaid-list` | 미납 대상 목록 |
| 올해 분양 | `/work/exec/sales` | 당해 분양 |
| 연도별 계약 | `/work/exec/contracts` | 연도별 계약 집계 |
| 연도별 관리비 | `/work/exec/fees-by-year` | 연도별 관리비 |
| 그달 납부 | `/work/exec/paid` | 해당 월 납부 |
| 그달 미납 | `/work/exec/unpaid` | 해당 월 미납 |
| 전체 관리비 | `/work/exec/all-fees` | 전체 관리비 |

화면은 표·월/연 집계 중심입니다. 행을 눌러 원본 프로그램을 수정하는 흐름이 아닙니다.

### A-3. 읽는 방법(현장용)

1. **올해 관리비**로 당해 큰 그림을 봅니다.  
2. 미납이 보이면 **미납 명단**·**그달 미납**으로 좁힙니다.  
3. 분양·계약 추이는 **올해 분양**·**연도별 계약**으로 봅니다.  
4. 숫자가 비거나 이상하면 슈퍼바이저에게 **DB 업데이트**와 복사본 상태를 요청합니다.

### A-4. CEO와 슈퍼바이저 차이(이 권 기준)

| | CEO | 슈퍼바이저 |
|--|-----|------------|
| 경영관리 | O | O |
| 홈페이지관리 | X | O |
| 업무프로그램 | O | O |
| 슈퍼바이저 전용 | X | O |

CEO는 CMS·방문통계·관리자계정·DB수동동기화 메뉴가 없습니다.

### A-5. 문제 해결

| 증상 | 조치 |
|------|------|
| admin인데 경영이 안 보임 | 정상 |
| 표가 전부 0/빈값 | 복사본·동기화, 연도/월 조건 |
| 로그인 후 경영이 업무로 감 | 역할이 ceo/supervisor인지 확인 |

## B. 테크니컬 매뉴얼

### B-1. 접근

```ts
requireStatusStaff() // supervisor | ceo
// 그 외 → /work/contracts 등
```

NAV: `src/lib/exec-nav.ts` (`EXEC_NAV`)  
사이트맵: `isStatusStaff(role)` → `work.overview`(경영관리)

### B-2. 데이터

- 복사본 관리비·계약 등을 `readWorkStatus` 계열로 집계
- 원본 Cemetery에 실시간 질의가 아닌, **저장된 복사본 기준**이므로 최신성은 동기화에 좌우됨
- 개인·묘번이 표에 나올 수 있음 → 문서 캡처·출력물 취급 주의

### B-3. 집계 해석 시 주의

- “올해”·“그달”은 **한국시간·데이터에 적힌 일자 필드** 기준인지 화면 라벨을 확인
- 미납/완납 구분은 복사본 `status` 값에 의존
- 경영 숫자와 슈퍼바이저 원장 건수가 어긋나면 동기화 시각·필터를 먼저 맞춤

- [ ] EXEC_NAV 8화면 로드
