# 5-A. 슈퍼바이저 운영 설명서

**슈퍼바이저(`supervisor`) 전용**입니다.  
방문통계·DB 업데이트·관리자 계정을 다룹니다.  
계약·관리비·영수증·업무보고·기초정보는 **5-B. 슈퍼바이저 계약·원장**을 받습니다.

---

## A. 유저 매뉴얼

### A-1. 메뉴

| 메뉴 | 경로 | 하는 일 |
|------|------|---------|
| 방문 통계 | `/supervisor/stats` | 공개 UV/PV, 기간·추이, 직원 페이지뷰 요약 |
| DB 업데이트 | `/work/sync` | 원본 → Mongo 복사본 수동 갱신 |
| 관리자 계정 | `/manage/admins` | 직원 계정 발급·수정(슈퍼바이저만) |
| 매뉴얼 다운로드 | `/supervisor/manuals` | 설명서 Word·PDF 받기 |

### A-2. 방문 통계

1. `/supervisor/stats`를 엽니다.
2. 오늘·7일·30일·누적 공개 방문자(UV)·페이지뷰(PV)를 봅니다.
3. 최근 30일 추이·직원 PV·조회 경로 요약을 확인합니다.
4. MongoDB가 없으면 통계를 보여줄 수 없습니다.

### A-3. DB 업데이트

1. `/work/sync`에서 **DB 업데이트**를 실행합니다.
2. 결과 건수를 확인합니다.
3. 평소에는 한국시간 새벽 1시 차분 동기화가 있을 수 있습니다.
4. 원본 비밀번호는 설명서에 적지 말고 서버 환경변수만 씁니다.

### A-4. 관리자 계정

1. `/manage/admins`에서 직원 계정을 관리합니다.
2. admin은 CMS·업무만, 슈퍼바이저 메뉴·DB동기화·이 계정 화면은 못 씁니다.
3. admin은 한국시간 09:00–18:00만 세션이 유지됩니다.

---

## B. 테크니컬 매뉴얼

### B-1. 가드

- `/supervisor/*` → `requireSupervisor`
- `/work/sync` → 슈퍼바이저
- `/manage/admins` → `requireCmsStaff(true)`
- `/api/supervisor/manuals/...` → 슈퍼바이저

### B-2. 환경

| 기능 | 필요 |
|------|------|
| 방문 통계 | `MONGODB_URI` |
| DB 업데이트 | `MONGODB_URI`, `CEMETERY_SOURCE_*` |
| 새벽 차분 | instrumentation, work-sync-timer |

### B-3. 동기화 요지

- 수동: 전면에 가깝게 다시 받음
- 야간: 바뀐 것만, 원본에 없는 행은 삭제하지 않음

끝.
