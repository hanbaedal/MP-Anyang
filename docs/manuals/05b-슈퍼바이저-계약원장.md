# 5-B. 슈퍼바이저 계약·원장 설명서

**슈퍼바이저(`supervisor`) 전용**입니다.  
계약관리·관리비내역·영수증관리·업무보고/현황·기초정보를 다룹니다.  
방문통계·DB·계정은 **5-A. 슈퍼바이저 운영**을 받습니다.

업무프로그램(`/work/...`)과 메뉴 이름이 같아도 경로와 기능이 다릅니다.

---

## A. 유저 매뉴얼

### A-1. 메뉴

| 메뉴 | 경로 | 하는 일 |
|------|------|---------|
| 계약관리 | `/supervisor/contracts` | 검색·계약부 열람 |
| 관리비내역 | `/supervisor/fees` | 기간·납부구분, 내역 모달 |
| 영수증관리 | `/supervisor/receipts` | 기간·종류, 영수증 모달 |
| 업무보고/현황 | `/supervisor/reports` | 목록·업무일지 모달 |
| 기초정보 | `/supervisor/base` | 탭별 목록·상세 |

### A-2. 계약관리

묘번·사용자·연고자·전화·종류로 검색합니다. Mongo 복사본만 보며, 페이지는 약 30건입니다.

### A-3. 관리비내역

청구일자 구간·납부구분으로 조회하고, 행을 누르면 내역 모달이 열립니다. 금액 0은 0으로 표시합니다.

### A-4. 영수증관리

기간·묘번·종류로 조회하고, 행을 누르면 영수증내역 모달이 열립니다. 저장·출력·삭제는 조회 중심입니다.

### A-5. 업무보고/현황

작성일자를 누르면 업무사항·예정사항·자재·특기·출근을 봅니다.

### A-6. 기초정보

탭: 묘지정보, 관리비기준, 석물코드, 회사정보, 사용자, 상담코드.  
검색 라벨은 탭마다 다르고, 회사는 검색칸이 없습니다. 사용자에 비밀번호 칸은 없습니다.  
묘지정보는 원본 목록 순서입니다.

### A-7. 업무프로그램과 구분

| 하고 싶은 일 | 갈 곳 |
|--------------|--------|
| 전 직원 계약 목록 | `/work/contracts` |
| 계약부·전화 검색 | `/supervisor/contracts` |
| 청구일·모달 | `/supervisor/fees` |
| 일지·기초 | `/supervisor/reports`, `/supervisor/base` |

---

## B. 테크니컬 매뉴얼

### B-1. 저장

contracts, contract_files, fees, receipts, work_reports, cemetery_info, base_items

### B-2. 현재 범위

조회·검색·모달/상세 읽기 중심. 원본의 저장·삭제·출력은 미구현 또는 부분일 수 있습니다.

끝.
